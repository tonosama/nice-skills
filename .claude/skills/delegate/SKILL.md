# Delegate

## 使うタイミング

delegate エージェントは、その固有のコア機能が必要なタスクに使う。これは組み込みの pi エージェントである。

## 手順

1. delegate エージェントを直接呼び出すか、chain／parallel task 経由で呼び出す。
2. 必要な要件やコンテキストを渡す。
3. delegate が専門役割（計画、調査、レビュー、オーケストレーションなど）を実行する。

## 落とし穴

- 明確な指示を渡すこと。組み込みエージェントは強力だが、よく定義された目標が必要。
- 複数ステップのタスクでは、異なるエージェント間で情報を渡す chain の利用を検討する。

## 検証

- delegate エージェントが要求フォーマットで期待どおりの出力を返す。
- ロジックがその役割に応じた期待挙動に沿っている。
