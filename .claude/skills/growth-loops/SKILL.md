# グロースループ

## 概要
持続的なトラクションを生むグロースループ（フライホイール）を特定・設計する。このスキルは実証された 5 つのグロースループメカニズムを評価し、有料獲得への依存を減らしプロダクト主導の成長を築く。

## 使用タイミング
- 製品の成長メカニズムを設計するとき
- 持続的なバイラルまたは紹介トラクションを構築するとき
- 有料獲得への依存を減らすとき
- 競合の成長戦略を分析するとき
- プロダクト主導成長（PLG）向けに製品を最適化するとき

## 5 つのグロースループタイプ

### 1. Viral Loop
ユーザーが製品内で作ったコンテンツが外部プラットフォームで共有され、新規ユーザーを製品に呼び戻す。
- **Mechanism**: ユーザーが製品内でコンテンツ作成 → ソーシャル／外部で共有 → 新規ユーザーが発見してサインアップ
- **Example**: リンク共有される Figma デザイン、メールで共有される Loom 動画
- **Strength**: コンテンツが本質的に共有可能ならユーザー獲得は指数的
- **Challenge**: 高度に共有可能なアウトプットと強い共有インセンティブが必要

### 2. Usage Loop
ユーザーが製品内で価値やコンテンツを作り、共有することで新規ユーザーを招いたり再エンゲージを促す。
- **Mechanism**: ユーザーが作成 → 作成物を共有 → 他者が消費 → エンゲージしたユーザーになる
- **Example**: Twitter スレッド、Medium 記事、公開共有される Notion テンプレート
- **Strength**: 製品利用とネットワーク効果に直接結びつく成長
- **Challenge**: コンテンツ作成の摩擦を極めて低くする必要がある

### 3. Collaboration Loop
ユーザーが同僚を共同作成・コラボに招待し、組織内のユーザーベースを広げる。
- **Mechanism**: ユーザーが作成 → コラボのため同僚を招待 → 同僚が製品価値を発見
- **Example**: Google Docs の招待、Figma チームプロジェクト、Slack チャンネル
- **Strength**: 組織への深い浸透と高いリテンション
- **Challenge**: コラボ／チーム向け製品で最も効く

### 4. User-Generated Loop
ユーザーが他ユーザーの作成物から新コンテンツや機能を発見し、自らも作成・共有する。
- **Mechanism**: ユーザーがコンテンツ発見 → 類似コンテンツ作成 → 共有 → 他者が発見
- **Example**: TikTok、Pinterest、YouTube のトレンドがクリエイター参加を促進
- **Strength**: コンテンツのフライホイールとネットワーク効果を生む
- **Challenge**: 維持するには質の高いコンテンツのクリティカルマスが必要

### 5. Referral Loop
ユーザーが報酬・インセンティブ・社会的認知と引き換えに潜在ユーザーを招待する。
- **Mechanism**: ユーザーが紹介 → 紹介されたユーザーが参加 → 紹介者が報酬 → さらに紹介を共有
- **Example**: Dropbox 紹介ボーナス、Uber ライダー紹介、PayPal サインアップボーナス
- **Strength**: 獲得を直接インセンティブ化；ROI 測定が容易
- **Challenge**: ユニットエコノミクスを損なわない価値あるインセンティブが必要

## 進め方

### Step 1: 製品価値を定義
ユーザーが体験するコア価値を明確化：
- 製品内での主要アクション
- ユーザーアクションあたりの価値
- 存在するネットワーク効果（あれば）
- 体験上の摩擦ポイント

### Step 2: ループ適合を評価
どのグロースループが製品と整合するかを見る：
- 製品タイプ（コラボ、コンテンツベース、ユーティリティなど）
- ターゲットユーザーの行動と共有習慣
- 既にあるネットワーク効果
- 既存ユーザーベースとエンゲージメント

### Step 3: ループメカニズムを設計
具体的なループ実装を作る：
- 共有や招待を開始するトリガー
- 参加インセンティブ（内在的または外在的）
- 共有のしやすさ
- 招待からアクティベーションへのコンバージョン率
- ユーザーあたりのループ反復頻度

### Step 4: ループ係数を計算
成長速度を見積もる：
- サイクルあたりユーザーあたりの招待／共有数
- 招待から新規ユーザーへのコンバージョン率
- サイクルあたりの純増ユーザー
- 1 サイクルあたりの時間

### Step 5: ループを構築
レバレッジが最も高いループから実装：
- 製品に最も自然なループから開始
- メッセージと摩擦を最適化
- ループ指標とコンバージョン率を測定
- 時間とともに結果を複利化

## 入力形式
$ARGUMENTS で以下を渡す：
- 製品説明と主要ユーザーアクション
- ターゲットユーザー属性と行動
- 既存の共有／コラボ機能
- 現行の成長チャネルと指標
- 制約または機会

## 出力
グロースループ分析として以下を含む：
- 自社製品向け 5 ループタイプの順位付き評価
- 実装計画付きの推奨プライマリグロースループ
- 時間をかけて重ねるセカンダリループ
- 主要指標と測定フレームワーク
- 30-60-90 日の実装ロードマップ
- 想定ループ係数と成長見込み

## フレームワーク
Ognjen Bošković のグロースループ研究に基づく。製品ネイティブな共有・コラボメカニズムによる獲得の複利化に焦点。

## ヒント
- 1 つのループから始め、習熟してから複雑化する
- Viral ループは最も速く複利化するが構築に時間がかかる
- Collaboration ループは最強のリテンションと LTV を生む
- 最適化フェーズでは週次でループ健全性を測る
- スケール稼働後はループを組み合わせて乗数的効果を狙う
