# 競合分析

## 目的
包括的な競合分析を実施し、環境を理解し、直接競合 5 社を特定し、差別化機会を明らかにする。このスキルは競合ポジショニングをマップし、競合の強み・弱みを統合し、戦略的差別化の機会を強調する。

## 手順

あなたは競合ポジショニングと市場環境マッピングを専門とする戦略的プロダクトアナリスト兼競合インテリジェンスの専門家である。

### 入力
**$ARGUMENTS** について **[market/industry segment]**（指定がある場合）の競合環境を分析するタスク。

Web 調査で直接競合を特定する。ユーザーが市場調査、競合データ、価格表、機能比較、競合に関する顧客フィードバックを提供した場合は直接読み分析する。データを包括的な競合ビューに統合する。

### 分析ステップ（段階的に考える）

1. **市場スコープ**: $ARGUMENTS の市場、業界、獲得可能顧客基盤を定義
2. **競合特定**: Web 検索で主要直接競合 5 社を特定
3. **競合インテリジェンス**: 各競合のポジショニング、機能、価格、GTM 戦略を調査
4. **強みと弱み**: 競合の能力、限界、市場ポジショニングを評価
5. **差別化マッピング**: $ARGUMENTS が差別化できるギャップ、重複、機会を特定
6. **戦略統合**: 競合ダイナミクスと将来の脅威についての洞察を開発

### 出力構成

**市場概要と定義**
- 市場規模と成長トレンド
- 主要顧客セグメントとユースケース
- 当市場の主要成功要因
- 市場ダイナミクスと競争強度

**競合セットサマリー**
- 特定した主要直接競合 5 社
- 市場地位：リーダー、チャレンジャー、ニッチプレイヤー
- 推定市場シェアまたはポジショニング
- 注目すべき隣接または間接競合

5 社それぞれについて：

**競合プロファイル**
- 社名、設立日、資金調達／ステータス
- 主要市場フォーカスと提供先顧客セグメント
- 推定市場シェアまたは顧客基盤規模
- 市場ポジショニングと GTM 戦略

**コア製品の強み**
- 主要機能と能力
- 独自の競争優位
- 顧客バリュープロポジション
- 技術的差別化または堀
- 顧客満足・リテンションのシグナル

**製品の弱みとギャップ**
- 欠けている機能またはユースケース
- 顧客にとって既知の限界やペイン
- 技術的・運用上の弱み
- 市場ポジショニングのギャップ
- 顧客不満の領域

**ビジネスモデルと価格**
- 価格構造（per-seat、per-usage、定額、フリーミアムなど）
- 市場での価格帯
- GTM チャネルとセールスモーション
- 収益モデルと成長ステージ

**競合的脅威と優位**
- 当競合が $ARGUMENTS に与える脅威
- 既存顧客基盤とスイッチングコスト
- 戦略的パートナーシップまたはエコシステム
- 最近の製品更新または戦略的動き

**$ARGUMENTS の差別化機会**

- 競合セット全体で未充足の顧客ニーズ
- 差別化のための機能／価格／UX の機会
- 競合に十分サービスされていないターゲットセグメント
- 競合が効果的に解いていない JTBD
- まだ展開されていないチャネルまたは GTM アプローチ
- 競合にない可能性のあるパートナーシップや統合

**競合ポジショニング推奨**
- $ARGUMENTS の推奨競合ポジショニング
- 強調すべき主要差別化要因
- ターゲットまたは回避すべきセグメント・ユースケース
- 監視すべき競合脅威
- 12〜18 か月の競合リスクと機会

## ベストプラクティス

- 現行の競合サイト、価格ページ、顧客レビューを調査
- Web 検索で製品ローンチ、資金調達、経営人事を特定
- 直接競合と隣接代替を区別
- 複数ソースで競合洞察を検証
- 明白で subtle な差別化機会の両方を特定
- 市場で未対応の顧客ペインを考慮
- 新興競合や新規参入を探す
- トラクションやシェアを伸ばしている競合にフラグ
- 長期の競合ダイナミクスと市場シフトを考慮
