## カスタマージャーニーマップ

認知からアドボカシーまでエンドツーエンドの顧客体験をマップし、各段階の感情、ペインポイント、改善機会を特定する。

### コンテキスト

**$ARGUMENTS** のカスタマージャーニーマップを作成する。

ユーザーがファイル（インタビュー記録、アンケートデータ、分析、サポートチケット、既存ジャーニーマップ）を提供した場合はまず読み込む。URL があれば Web 検索で製品を理解する。

### 手順

1. **ペルソナを定義**：このジャーニーを歩むのは誰か。汎用ユーザーではなく JTBD を持つ具体的ペルソナを使う。

2. **ジャーニー段階をマップ**（製品に合わせて調整）：

   | Stage | Description |
   |---|---|
   | **Awareness** | 製品を最初にどう知るか？ |
   | **Consideration** | 何を評価するか？ どの代替と比較するか？ |
   | **Acquisition** | どうサインアップまたは購入するか？ |
   | **Onboarding** | 製品との初体験 — time to value |
   | **Engagement** | 定期利用 — 習慣形成 |
   | **Retention** | 何が継続利用を促すか？ チャーン要因は？ |
   | **Advocacy** | いつ・なぜ他者に推薦するか？ |

3. **各段階について文書化**：

   - **Touchpoints**: ユーザーが製品、ブランド、チームと接する場所（ウェブサイト、メール、アプリ内、サポート、ソーシャル）
   - **User actions**: この段階で行うこと
   - **Thoughts & questions**: 頭の中にあること（「時間に見合うか？」「どうやって…？」）
   - **Emotions**: 感じ方（ワクワク、混乱、イライラ、喜び）— スケールまたは絵文字で表現
   - **Pain points**: 摩擦、混乱、離脱リスク
   - **Opportunities**: この時点での体験改善方法

4. **クリティカルな瞬間を特定**：
   - **Aha moment**: コア価値を初めて体験する瞬間
   - **Moments of truth**: コミットまたは離脱を決める分岐点
   - **Churn triggers**: 最も多く離脱が起きる箇所

5. **ジャーニーマップ表を作成**：

   | Stage | Touchpoint | User Action | Emotion | Pain Point | Opportunity |
   |---|---|---|---|---|---|

6. **優先順位付き改善を提案**：
   - コンバージョン・リテンションへの影響が最大のペインはどれか？
   - すぐ効くクイックウィンは？
   - 深い投資が必要だがリターン最大のものは？

段階的に考える。Markdown ドキュメントとして保存。視覚的ジャーニーマップは、本分析を基に Miro や FigJam で作成することをユーザーに提案する。
