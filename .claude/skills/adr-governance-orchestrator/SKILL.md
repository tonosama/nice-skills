# ADRガバナンスオーケストレーター - 完全なライフサイクル管理

このスキルはすべてのアーキテクチャ決定記録（ADR）操作の中央コマンドとして機能します。漠然とした「選択を行う必要がある」から正式に記録され、ゲートキーピングされ、インデックス化されたアーキテクチャ決定への移行を自動化します。

## 使用場面
以下のような場合にこのスキルを使用します：
- ゼロから新しいADRプロセスを開始する。
- 既存のADRを監査してギャップや古いレコードを見つける。
- 新しい情報で既存のADRを更新する。
- 新しい決定で古い決定を上書きする。
- アーキテクチャ決定ログの完全な「監査」を実行する。

## オーケストレーションされたワークフロー
起動されると、このスキルは厳密な順次パイプラインに従います：

### フェーズ0：インフラストラクチャ検証
1. **ディレクトリチェック**: `docs/adr`が存在するか確認する。
2. **自動プロビジョニング**: ディレクトリが欠落している場合、`install-adr-gatekeeper`を自動的に起動してインフラストラクチャを初期化し、ルールを設定し、初期インデックスを作成する。
3. **継続性**: プロビジョニング後、標準的な発見と分析フェーズに進む。

### フェーズ1：発見と分析
1. **既存状態の監査**: `adr-discovery`を呼び出して既存のADRを特定し、潜在的な重複や競合を検出する。
2. **要件収集**: ユーザーのリクエストを分析して以下を決定する：
   - **コンテキスト**（なぜこれをするのか？）
   - **ドライバー**（パフォーマンス、コスト、セキュリティなど）
   - **代替案**（他に何を検討したか？）
   - **結果**（トレードオフは何か？）

### フェーズ2：草稿作成と執筆
3. **テンプレート選択**: 分析に基づき、適切なテンプレート（MADR、Nygard、またはYステートメント）を選択する。
4. **コンテンツ生成**: `adr-authoring`を起動して草稿を生成する。
5. **洗練**: ユーザーと草稿をレビューし、「知識デルタ」（専門家のみのトレードオフ）をキャプチャする。

### フェーズ3：ゲートキーピングと検証
6. **ガバナンスチェック**: 草稿を`adr-gatekeeper`に渡す。これはADRが「良い」だけでなく「準拠している」ことを確認する（例：冗長なコンテンツなし、適切なステータス、明確な結果）。
7. **修正**: ゲートキーパーが問題を特定した場合、それらに対処するために作成フェーズに戻る。

### フェーズ4：ライフサイクルと統合
8. **最終化**: 承認されたら、`adr-lifecycle-management`を起動して：
   - 正しいステータスを設定する（承認済み、提案済みなど）。
   - `docs/adr/`のマスターインデックス（README.md）を更新する。
   - 上書きリンクを処理する（古いADRを置き換える場合）。
9. **メモリ同期**: ローカルメモリキャプチャをトリガーして、新しいレコードがプロジェクトの長期メモリ（OKF/ChromaDB）にインデックス化されるようにする。

## 自由度のキャリブレーションと制約
- **制約レベル: 高**
  - **厳格さ**: パイプラインの順序は必須です。ゲートキーピングフェーズまたはインデックス更新をスキップしてはいけません。
  - **自由度**: ADRの具体的なコンテンツは、「結果」要件を満たす限り柔軟です。

## 重要なアンチパターン（NEVERリスト）
| アンチパターン | 説明 | 代替/解決策 |
| :--- | :--- | :--- |
| **ゲートキーパーをスキップしてはいけない** | チェックをバイパスすると一貫性のないレコードと「トークンの無駄」につながる。 | 最終化の前に常にゲートキーパーチェックを実行する。 |
| **ADRを削除してはいけない** | 決定が悪くても、その決定の記録は重要です。 | 「非推奨」または「上書き済み」とマークする。 |
| **リンクを失ってはいけない** | 新しいADRをそれが上書きするものにリンクしないと決定チェーンが壊れる。 | ライフサイクルフェーズで常に双方向リンクを使用する。 |

## 検証
1. 新しいADRが正しいディレクトリにユニークなIDで作成される。
2. ADRが`adr-gatekeeper`の検証を通過する。
3. `docs/adr/README.md`のマスターインデックスが更新される。
4. 決定がプロジェクトのメモリシステムにキャプチャされる。
