# Researcher

## 利用タイミング
researcher エージェントの中核機能が必要なタスクで利用する。組み込み pi エージェントである。

## 手順
1. researcher エージェントを直接、または chain/parallel task 経由で呼び出す。
2. 必要な要件やコンテキストを渡す。
3. researcher が専門ロール（計画、調査、レビュー、オーケストレーションなど）を実行する。

## 落とし穴
- 組み込みエージェントは強力だが、目標が明確である必要がある。指示ははっきり書くこと。
- 多段タスクでは chain でエージェント間に情報を受け渡すことを検討する。

## 検証
- researcher エージェントが要求フォーマットで期待どおりの出力を返すこと。
- ロジックがそのロールに応じた想定動作に従っていること。
