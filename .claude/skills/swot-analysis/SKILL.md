# SWOT Analysis

## Metadata
- **Name**: swot-analysis
- **Description**: プロダクト向けの詳細 SWOT 分析。強み、弱み、機会、脅威と実行可能な推奨を特定する。
- **Triggers**: SWOT analysis, strengths weaknesses, SWOT matrix, strategic assessment

## 手順

$ARGUMENTS 向けに SWOT 分析を行う戦略アナリストとして振る舞う。

プロダクト成功と競争ポジションに影響する内外要因を徹底評価する。

## 入力要件
- プロダクト説明と現状
- 競争環境と市場文脈
- 会社の能力、リソース、制約
- 市場トレンドと業界動向
- 顧客フィードバックまたは利用データ（任意）

## SWOT 分析フレームワーク

### 1. Strengths（内部・ポジティブ）
内部で持つ能力・優位は？

- 独自の能力・専門性
- ブランド認知・評判
- 顧客関係・ロイヤルティ
- 技術・IP 優位
- コスト優位・運用効率
- チームの才能・経験
- 既存顧客基盤・流通

### 2. Weaknesses（内部・ネガティブ）
内部の制限・ギャップは？

- リソース制約（予算、チーム規模、スキル）
- 技術・インフラ制限
- ブランド認知・市場プレゼンス不足
- 弱い顧客関係・高離脱
- 競合比較で高いコスト構造
- 古いプロセス・レガシーシステム
- 特定人物・パートナーへの依存

### 3. Opportunities（外部・ポジティブ）
活用できる外部トレンド・市場動向は？

- 成長する市場セグメント・顧客ニーズ
- 新解を可能にする技術進歩
- 自アプローチに有利な規制変化
- 競合の弱み・市場ギャップ
- パートナーシップ・買収機会
- 隣接市場・セグメントへの拡大
- 顧客嗜好・行動のシフト

### 4. Threats（外部・ネガティブ）
ネガティブに影響しうる外部要因は？

- 新規・強力な競合
- 顧客嗜好・ニーズの変化
- 技術的破壊・陳腐化
- 規制変化・コンプライアンスリスク
- 景気後退・市場縮小
- サプライチェーン混乱
- サプライヤー・パートナー統合

## 出力プロセス
1. 強みを5–7件特定（競争優位は正直に）
2. 弱みを5–7件列挙（矮小化せず、対処可能なギャップに焦点）
3. 機会を5–7件マップ（市場規模・整合で優先）
4. 脅威を5–7件フラグ（確率・影響を評価）
5. クロスリファレンスで戦略的洞察:
   - 強みで機会をどう捉えるか？
   - 弱みをどう補強し脅威を緩和するか？
   - どの機会が弱みを克服するか？
   - どの脅威が弱みを突くか？
6. 3–5の戦略的推奨を策定
7. アクションとオーナーを優先付け
8. 進捗追跡メトリクスを特定

## 戦略的応用
- **Build**: 強み + 機会に踏み込む
- **Defend**: 弱みを固め脅威を緩和
- **Pivot**: 競争力学を変える機会を探索
- **Exit**: 脅威が多く競争ポジションが弱い場合

## 注意事項
- SWOT は内部対外部の評価
- 文脈重要：競合・業界基準と比較
- 四半期または市場変化時に SWOT 更新
- ロードマップ、パートナーシップ、リソース配分に活用
- 機会・脅威は現行と新興の両方の動態を考慮
