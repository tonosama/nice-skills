# Value Proposition

## Metadata
- **Name**: value-proposition
- **Description**: JTBD フレーミング付き6部テンプレートで詳細バリュープロポジションを生成。説得力ある顧客価値設計の実例を含む。
- **Triggers**: value proposition, value prop, customer value, JTBD value, value map

## 手順

$ARGUMENTS 向けに明確なバリュープロポジションを設計するプロダクト戦略家として振る舞う。

プロダクトが届ける顧客価値を言語化する包括的バリュープロポジションを策定する。

## 入力要件
- プロダクト説明と機能
- ターゲット顧客セグメントと課題
- 競合代替と現行解
- 顧客インサイトまたは市場データ

## Value Proposition テンプレート

### 6部構成

**1. Who**
- このバリュープロポジションは誰向けか？
- どの顧客セグメントを扱うか？
- 特性と制約は？

**2. Why (Problem)**
- 顧客の中核課題・ニーズは？
- Job to Be Done (JTBD) は？
- 達成したい望む成果は？

**3. What Before**
- 顧客の現状は？
- 今日この課題をどう解いているか？
- 現行アプローチの摩擦・痛みは？

**4. How (Solution)**
- プロダクトは課題をどう解くか？
- 価値を届ける具体的機能・能力は？
- なぜ代替より優れているか？

**5. What After**
- 改善された成果・未来像は？
- 顧客の生活・仕事はどう変わるか？
- 以前不可能だったことが可能になることは？

**6. Alternatives**
- 顧客が使える他の解は？
- なぜ自社を選ぶか？
- 代替からのスイッチングコスト・摩擦は？

## 例: Canva
- **Who**: マーケ用グラフィックが必要だがデザイナーではない人
- **Why**: プロ品質のデザインが必要だがデザイナー雇用や複雑ツールは使えない
- **What Before**: PowerPoint、Photoshop（複雑すぎ）、高価なデザイナー雇用
- **How**: ドラッグ＆ドロップテンプレート、組み込みデザイン要素、AI 支援、直感的 UI
- **What After**: 数分でプロ品質デザイン、キャンペーン高速立ち上げ、デザインコスト削減
- **Alternatives**: Photoshop（複雑）、Fiverr（遅く高価）、Canva 競合（テンプレ少、UX 難）

## 出力プロセス
1. ターゲット顧客セグメントを特定・プロファイル化
2. 中核課題と JTBD を定義
3. 現状と摩擦ポイントを記述
4. プロダクトの解決方法を言語化する
5. 改善された成果を描く
6. 競合代替と比較
7. 簡潔なバリュープロポジション声明（1–2文）を作成
8. マーケ用ポジショニング声明を策定

### ドメインコンテキスト

**本テンプレート vs Strategyzer's Value Proposition Canvas**: Strategyzer（Alexander Osterwalder）のキャンバスは広く使われるが構造上の限界がある。本6部 JTBD テンプレート（Paweł Huryn、Aatir Abdul Rauf）はそれに対処する：

- **顧客ファースト**: 顧客（Who/Why）から始め解決策へ。Strategyzer は左にプロダクトを置き、しばしば顧客課題より自社ソリューションから始める。
- **1セグメントずつ**: 1パスで1セグメント向け。Strategyzer は複数プロダクト／サービスを同時マッピングしやすく焦点が薄まる。
- **明示的代替**: 第6部（Alternatives）で顧客が自社なしで使うものを名指し、優位理由を述べる。Strategyzer に同等セクションはない。
- **より単純な構造**: What before → How → What after は、Jobs/Pains/Gains と Pain Relievers/Gain Creators/Products に分けるより記入しやすい。分離は何をどこに書くか混乱を生みやすい。
- **実行可能な出力**: 最終 Value Proposition Statement はマーケ・営業・オンボーディングですぐ使える。Strategyzer は再利用可能な声明を産まない。

複雑な顧客ニーズを持つ成熟プロダクトで pains/gains を詳細分解するには Strategyzer を使う。明確さ・速度・実行可能な出力には本6部テンプレートを使う。

## 注意事項
- JTBD は人口統計ではなく顧客が達成しようとする進歩に焦点
- バリュープロポジションはセグメント固有；グループごとに異なりうる
- 強いバリュープロポジションほどマーケ・営業・プロダクト判断が楽になる
- 確定前に実顧客でテスト
- **Value Curve**（Blue Ocean Strategy）で主要因子について競合比較を可視化
