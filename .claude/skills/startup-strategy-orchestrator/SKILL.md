# スタートアップ戦略オーケストレーター — アイデアから投資へ

アーリーステージのスタートアップ向け包括計画プロセスを管理するスキル。市場検証、財務モデル化、投資家向けビジネスケース構築までの重要ステップをガイドする。

## 使用タイミング
次の場合にこのスキルを使う:
- 新規スタートアップまたはプロダクトを計画するとき。
- Seed または Series A の資金調達準備をするとき。
- 3〜5 年のロードマップと財務予測を定義するとき。
- 人員ニーズとユニットエコノミクスを決めるとき。

## 編成ワークフロー
このスキルは次のフェーズを順に実行する:

### フェーズ 1: 市場機会分析
1. **市場規模**: `startup-analyst` を呼び出し TAM、SAM、SOM を算出する。
2. **機会評価**: `startup-business-analyst-market-opportunity` を呼び出し競合環境を分析し差別化を特定する。

### フェーズ 2: 財務モデリング
3. **財務予測**: `startup-financial-modeling` を呼び出し 3〜5 年の売上・コスト・キャッシュフローモデルを構築する。
4. **指標フレームワーク**: `startup-metrics-framework` を呼び出し主要 KPI（CAC、LTV、Burn Rate）を定義する。

### フェーズ 3: オペレーションと統合
5. **人員計画**: `team-composition-analysis` を呼び出し採用ニーズと組織図を決定する。
6. **ビジネスケース統合**: `startup-business-analyst-business-case` を呼び出し全所見を投資家向けビジネスケース文書にまとめる。

## 自由度の調整と制約
- **制約レベル: 中**
  - **厳格性**: 市場 → 財務 → オペレーション → 統合の順序は必須。
  - **自由度**: 成長率、コンバージョン、ユニットエコノミクスの具体的な前提はユーザー入力に委ねる。

## 重要なアンチパターン（NEVER リスト）
| アンチパターン | 説明 | 代替 / 解決策 |
| :--- | :--- | :--- |
| **NEVER** バーンレートを無視する | ランウェイをモデル化しないと早期失敗につながる。 | 常に詳細なキャッシュフローとバーンレート分析を含める。 |
| **NEVER** データなしで「ブルーオーシャン」を主張する | 市場規模なしの独占主張は投資家に赤信号。 | すべての主張を `startup-analyst` で TAM/SAM/SOM に裏付ける。 |
| **NEVER** チーム計画を飛ばす | 優れた計画も実行する人材計画がなければ失敗する。 | 最終統合には必ず `team-composition-analysis` を含める。 |

## 検証
1. TAM/SAM/SOM の計算が完了している。
2. 売上とコストを含む 3〜5 年の財務モデルが作成されている。
3. 人員計画と組織図が定義されている。
4. 包括的な投資家向けビジネスケースが統合されている。
