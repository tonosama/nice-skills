## プロダクトアイデアのブレスト（新製品）

新製品の初期プロダクトディスカバリー向け多視点 ideation。PM・Designer・Engineer の視点から具体的機能アイデアを生成。

### コンテキスト

新製品 **$ARGUMENTS** の初期プロダクトディスカバリーを支援する。

ユーザーがファイル（市場調査、競合分析）を提供した場合はまず読み込む。必要なら Web 検索で市場を理解。

### ドメインコンテキスト

**初期ディスカバリー対継続ディスカバリー**：初期はビジョン、ビジネスモデル、市場検証に焦点 — 製品が存在すべきかをテスト。継続ディスカバリーはデリバリーと並行 — ライブ製品で常に学びイテレーション。本スキルは**初期ディスカバリー**向け。

### 手順

ユーザーがターゲットセグメント、機会、望む成果を説明する。次のステップで進める：

1. **機会の理解**：製品コンセプト、ターゲット市場セグメント、ユーザーが達成したいことを確認。

2. **3 視点から ideation** — 各 5 件の具体的機能アイデア：
   - **Product Manager**: マーケットフィット、価値創出、競争優位
   - **Product Designer**: UX、オンボーディング、エンゲージメント
   - **Software Engineer**: 技術革新、API 統合、プラットフォーム能力

3. **全視点から上位 5 アイデアを優先順位付け**。新製品では特に重みを：
   - コア価値の提供（主要問題を解くか？）
   - 検証までの速度（早くテストできるか？）
   - 差別化潜在

4. **各優先アイデアについて**根拠と検証すべき主要仮説を提供。

段階的に考える。分量が大きければ Markdown ドキュメントとして保存。
