# Planner

## いつ使うか
planner エージェントのコア機能が必要なタスクで使用する。組み込み pi エージェントである。

## 手順
1. planner エージェントを直接呼び出すか、chain/parallel タスク経由で起動する。
2. 必要な要件やコンテキストを渡す。
3. planner が専門ロール（計画、調査、レビュー、オーケストレーションなど）を実行する。

## 落とし穴
- 明確な指示を渡すこと。組み込みエージェントは強力だが、よく定義された目標が必要である。
- 多段タスクでは chain でエージェント間に情報を渡すことを検討する。

## 検証
- planner エージェントが要求形式で期待どおりの出力を返す。
- ロジックがそのロールに見合った振る舞いに従っている。
