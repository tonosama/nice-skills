## リーンスタートアップ実験設計（新製品）

XYZ 仮説を作成し、pretotype 実験で新製品コンセプトを最小工数で検証する。

### コンテキスト

リーンスタートアップ手法で新製品コンセプト **$ARGUMENTS** の検証を支援する。

ユーザーがファイル（市場調査、ランディングページモック）を提供した場合はまず読み込む。

### 手順

1. **XYZ 仮説を作成**：「At least X% of Y will do Z」の形式
   - **X%**: ターゲット市場のうち関与すると期待する割合
   - **Y**: 特定ターゲット市場（例：「mid-size luxury sedan buyers」）
   - **Z**: 製品への関与方法

2. **仮説を最小工数でテストする pretotype 実験を 2〜3 件提案**。検討：
   - **Landing Page**: サインアップやクリックで関心を測定
   - **Explainer Video**: エンゲージメント指標で理解と訴求を測定
   - **Email Campaign**: 応答・CTR で需要を測定
   - **Pre-Order / Waitlist**: skin-in-the-game で支払意思を測定
   - **Concierge / Manual MVP**: 手動提供で価値を測定

3. **原則**（Alberto Savoia, *The Right It*）：
   - **Skin-in-the-Game**: 関心だけでなく支払意思をテスト。実コミット（時間・金銭・評判）だけが信頼できるシグナル。
   - **Your Own Data (YODA)**: 市場レポートや類推など Others' Data (ODP) に頼らず実験で自社データを集める。「あなたのアイデアの市場は、他人のアイデアの市場を気にしない。」
   - 意見ではなく実際の行動を測る

4. **各実験について**、検証する仮説、手法、指標、成功閾値を指定。

段階的に考える。分量が大きければ Markdown で保存。
